# Postponed issues

Known issues and limitations we've consciously decided **not** to fix yet —
captured here so they aren't forgotten and so the reasoning survives.

One Markdown file per issue, named with a short kebab-case slug
(e.g. `currency-locale.md`). Each file should cover:

- **Summary** — what the issue is.
- **Where** — the files / code involved.
- **Why postponed** — the reason it's deferred (scope, priority, blocked, …).
- **When to revisit** — the trigger or conditions that make it worth doing.

This is for deliberate deferrals, not a bug tracker. Fix-now bugs get fixed;
things that belong in a real tracker go there. This directory is for "we saw it,
we understand it, here's why it can wait."
